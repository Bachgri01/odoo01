WhatsApp OTP Authentication

Ce module permet une connexion Odoo via un code OTP envoyé par WhatsApp, avec une interface de validation intégrée au login standard.

Fonctionnalités

  • Bouton de login WhatsApp sur la page de connexion
  • Envoi d'un code OTP sur WhatsApp
  • Validation du code OTP et redirection vers Odoo
  • Page de vérification 2FA dédiée

Installation

  • Copier le module dans le dossier des modules Odoo.
  • Mettre à jour la liste des modules.
  • Installer le module depuis l'interface Odoo.

Configuration

Assurez-vous que le module web est installé et que l'accès à l'API UltraMsg est configuré correctement.

Remarques

Le code OTP expire après 2 minutes. Un message d'erreur s'affiche en cas de problème d'envoi ou de validation.
